# Roman Urdu Clinical Glossary

This glossary standardizes the Roman Urdu orthography used across ChronicCare AI's adaptive interview engine (v3), frontend prompts, and conversational option items.

Rules:
- Simple, colloquial phrasing as spoken in Pakistan and typed on messaging apps (WhatsApp).
- Exactly one canonical Roman Urdu spelling per medical/conversational term.
- Medical loanwords that patients routinely use in everyday speech remain standard (e.g. *sugar*, *BP*, *test*, *meter*, *cuff*, *dose*).
- Clinical units (`mg/dL`, `mmHg`, `mmol/L`) are retained verbatim.
