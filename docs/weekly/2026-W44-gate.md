## 2. Global Safety Invariants Verification

1. **"The Model Proposes, the Rules Decide"**:
   - Risk assessment runs strictly advisory.
   - `RISK_CAN_RAISE` can only escalate `routine -> review`. It cannot touch, modify, or lower urgent/emergency triage.
2. **Leak Defense Invariant**:
   - Patient endpoints (`/api/checkins/{id}/complete`) strictly omit numerical probabilities, regression model names, and versions.
3. **Emergency Bypass Invariant**:
   - In any emergency check-in, both `risk` and `explanation` evaluate to `null`. The LLM is never invoked during a crisis.
4. **Architectural Equivalence Invariant**:
   - The application behaves 100% identically whether `ORCHESTRATOR=direct` or `ORCHESTRATOR=graph` is set in the runtime environment.
5. **Mutation Integrity Invariant**:
   - All 40 safety and architectural mutations are verified and killed by automated unit test nodes (`scripts/verify_mutations.py`).
