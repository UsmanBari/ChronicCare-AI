## 3. What Slipped & Why

1. **Direct MIMIC-IV Execution Inside Assistant Sandbox:** Slipped to human-supervised offline execution. Under the PhysioNet Credentialed Data Use Agreement (DUA), raw patient records cannot be processed through cloud-based AI tools. Muhammad Saad executed `ml/mimic/trend_sanity.py` locally and pasted aggregate cohort metrics into `docs/TREND_EVAL.md`.
2. **API Contract Doc Inconsistency on Patient Risk:** `docs/API_RISK_EXPLAIN.md` Section 3 specified `risk` as a sub-object within `CheckinCompleteResponse`, whereas Sections 1, 2, and the running codebase enforce `risk: null` on patient endpoints (doctor-only triage safety rule). Rather than modifying clinical endpoints, GitHub Issue #128 was filed to correct the documentation specification to match the code.
3. **Live UI Verification of Risk/Explanation/OCR:** Live system testing on Netlify/Render marked these screens as `flag off: NOT RUN` because production environment flags (`RISK_ENABLED`, `EXPLAIN_ENABLED`, `OCR_ENABLED`) remain disabled until Release 2 deployment.
